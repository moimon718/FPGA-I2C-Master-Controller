# FPGA-Based I2C Master Controller

## Overview
Designed and synthesized an FPGA-ready I2C Master controller in Verilog using Vivado.

## Features
- Edge-based FSM architecture
- START/STOP condition generation
- ACK/NACK handling
- Serial address and data transfer
- FPGA synthesis and timing analysis

## Tools Used
- Vivado 2025.2
- Verilog HDL
- EDA Playground

## FPGA Flow Completed
- RTL Design
- Functional Simulation
- Waveform Verification
- FPGA Synthesis
- Timing Analysis
- RTL Schematic Verification
